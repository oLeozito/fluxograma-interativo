LEGENDA

Seta sólida: pré-requisito direto. Caixa tracejada (co-requisito): cursar juntas no mesmo semestre.

Ponto colorido: semestre sugerido. Badge: obrigatórias que a disciplina tranca, direta ou indiretamente; tracejado verde (0) = livre.

Passe o mouse para destacar a cadeia. Bolinhas do topo: clique para destacar só aquele semestre. Clique no card para marcar como cumprida (fica apagada e é salva neste navegador).

CH = carga horária; "(15h EXT)" = horas de extensão dentro dela. Vagas de optativa (OP, OH, OC): clique para escolher a disciplina e marcá-la como cumprida.
